# Automatización de bases de datos económicas y financieras

Proyecto desarrollado en **Python** para automatizar la **descarga, limpieza, procesamiento y almacenamiento** de información económica y financiera proveniente de distintas fuentes.

Los procesos se ejecutan automáticamente en la nube mediante **GitHub Actions**, con una actualización diaria programada para las **20:00 (hora de Argentina)**.

Las bases de datos se almacenan en **formato Excel** y se incluyen en el repositorio a modo de ejemplo, pudiendo ser descargadas y utilizadas directamente en computadoras personales.

### Tecnologías

* Python
* Pandas
* GitHub Actions

El objetivo es desarrollar un proceso **automatizado y reproducible** que permita mantener información económica y financiera estructurada, actualizada y fácilmente accesible.
